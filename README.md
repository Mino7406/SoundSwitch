# SoundSwitch

한국어 Windows에서 **기본 재생(오디오) 장치를 빠르게 전환**하는 초경량 AutoHotkey 도구.
소리 제어판을 자동으로 열고, 장치 목록에서 원하는 위치의 장치를 선택해 기본값으로 설정한다.

스피커 ↔ 헤드셋처럼 자주 바꾸는 장치를 **번호별 실행 파일 하나씩**으로 만들어 클릭 한 번에 전환하는 방식이다.

## 다운로드

실행 파일(`01.exe`, `02.exe`)은 저장소에 직접 포함하지 않고 **[Releases](../../releases/latest)** 탭에서 배포한다.
최신 버전을 받아 압축을 풀고 바로 실행하면 된다.

## 사용법

| 파일 | 동작 |
|------|------|
| `01.exe` / `01.ahk` | 장치 목록에서 **첫 번째 슬롯** 장치를 기본값으로 설정 |
| `02.exe` / `02.ahk` | 장치 목록에서 **두 번째 슬롯** 장치를 기본값으로 설정 |

실행하면 소리 제어판이 잠깐 떴다가 자동으로 닫히고 기본 장치가 바뀐다.
바탕화면이나 작업표시줄에 각 exe를 고정해두고 클릭해서 쓰면 편하다.

## 동작 원리

```
1. mmsys.cpl (소리 제어판) 실행
2. "소리" 창 대기
3. 재생 장치 목록(SysListView321)에서 선택 이동
4. "기본값으로 설정" 클릭
5. "확인" 으로 닫기
```

UI 컨트롤을 직접 조작하는 방식이라 별도 권한이나 외부 라이브러리가 필요 없다.

## 요구 사항

- **한국어 Windows** (창 제목 "소리", 버튼 "기본값으로 설정" / "확인" 이 하드코딩됨)
- 소리 제어판이 클래식 UI로 열리는 버전 (Windows 10 등)
- 소스 실행 시 [AutoHotkey v1.1](https://www.autohotkey.com/) 필요

## 빌드 (선택)

소스(`.ahk`)를 exe로 만들려면 AutoHotkey에 포함된 **Ahk2Exe** 사용:

```
Ahk2Exe.exe /in 01.ahk /out 01.exe
```

또는 `.ahk` 우클릭 → *Compile Script*.

## 제한 사항

- **언어 의존**: 영어 등 다른 언어 Windows에서는 창/버튼 이름이 달라 동작하지 않음.
- **Windows 11**: 소리 설정 UI가 바뀌어(설정 앱 기반) 그대로는 동작하지 않을 수 있음.
- 장치 순서가 바뀌면 슬롯 번호와 실제 장치가 어긋날 수 있음.
